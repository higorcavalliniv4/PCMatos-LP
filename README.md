# LP PC Matos

Landing page responsiva e mobile-first criada a partir do layout da PC Matos.

## Publicação no Vercel

1. Importe este repositório no Vercel.
2. Selecione `Other` como framework.
3. Não é necessário comando de build.
4. Use a raiz do repositório como diretório de saída.

## WhatsApp

Edite `WHATSAPP_NUMBER` no arquivo `script.js` usando apenas números, incluindo DDI e DDD. Exemplo: `5541999999999`.

Enquanto o número estiver vazio, os botões levam até a seção final da página.
